# Resource: proxmox_network_linux_eth

Manages a Linux Ethernet network interface in a Proxmox VE node.

The physical Ethernet interface must already exist on the Proxmox VE node. This resource configures the existing interface through the node network API.

## Example Usage

```terraform
resource "proxmox_network_linux_eth" "example" {
  name      = "eno1"
  node_name = "pve"

  autostart = false
  comment   = "Managed by OpenTofu"
  mtu       = 1500
}
```

## Schema

### Required

- `name` (String) The physical Ethernet interface name. The interface must already exist on the Proxmox VE node.
- `node_name` (String) The name of the node.

### Optional

- `address` (String) The interface IPv4/CIDR address.
- `address6` (String) The interface IPv6/CIDR address.
- `autostart` (Boolean) Automatically start interface on boot (defaults to `true`).
- `comment` (String) Comment for the interface.
- `gateway` (String) Default gateway address.
- `gateway6` (String) Default IPv6 gateway address.
- `mtu` (Number) The interface MTU.
- `timeout_reload` (Number) Timeout for network reload operations in seconds (defaults to `100`).

### Read-Only

- `id` (String) A unique identifier with format `<node name>:<iface>`.
